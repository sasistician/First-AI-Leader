# The AI-First Leader：网站首页信息（中文译文）

本文件是 sasistician.com 英文首页内容的忠实中文翻译，供语音向导检索使用。网站没有公布价格和日期。

## 关于课程

The AI-First Leader 是一门为期五周、基于 Claude Code 的直播小班课程。无需任何编程经验。每节课都建立在上一节的基础上，课程结束时，你将交付一个真正的智能体，让它基于你自己的知识运行，并为你的组织制定一份 AI 路线图。

这是一个面向高级和中层领导者的小班在线课程，专为 AI 优先的领导者打造。

## 为什么参加这门课

在 AI 时代重塑自己。用五周时间，不再只是和 AI 聊天，而是开始指挥它，覆盖你自己的工作和你所带领的团队。把整项工作委派给一组智能体，而不是一次一个任务地提示聊天机器人。编排，其实就是管理。

## The AI-First Leader 的五周内容

五周时间，从 AI 用户成长为 AI 领导者，推动你的组织完成 AI 转型。

- 第 1 周 · 思维模式 · 你的第一个智能体：从提示聊天机器人到指挥智能体。自动化一项真实的重复性任务，零代码。
- 第 2 周 · 知识 · 落地：把 Claude 连接到你自己的文档，并让它持续记住你的工作方式。带走一个了解你业务的 AI。
- 第 3 周 · 编排 · 委派：设计一个多步骤工作流或一组子智能体，端到端负责一项重复性工作。
- 第 4 周 · 战略 · 运营模式：制定你的 AI 优先机会地图和按优先级排序的 90 天路线图。
- 第 5 周 · 结业项目 · 交付与认证：在直播展示中完成并答辩你的结业项目智能体，带走一个你拥有的 AI 产品，并获得认证。

## The AI-First Engineer

网站上的第 0 至第 5 周课程讲义来自姊妹课程 The AI-First Engineer，这是一门面向软件工程师的 Claude Code 构建者课程，涵盖基础、Claude Code 基础、上下文工程、Skills、MCP，以及编排、护栏与评估。讲义提供英文和中文版本。

关于编程：The AI-First Leader 无需任何编程经验。The AI-First Engineer 面向软件工程师：实验在终端中基于 Python 代码仓库进行（git、uv、pytest），不过学员主要是指挥 Claude Code 编写大部分代码，而不是全部手写。

## 讲师

课程由 Bilal Farooq 讲授。他是一位资深 AI 专业人士，拥有 20 多年在澳大利亚、新西兰、马来西亚、阿联酋、美国和巴基斯坦的电信、银行、零售和咨询企业的从业经验。他在组建和培养高绩效数据科学团队方面有丰富经验，并担任一家旧金山初创公司的生成式 AI / 智能体 AI 顾问。他曾为从六年级到博士阶段的学生设计数据科学课程，并有丰富的数据科学、生成式 AI 和智能体 AI 教学经验。

## 术语

- MCP 是 Model Context Protocol（模型上下文协议）的缩写：一个把 Claude 连接到外部工具和数据的开放标准，在 The AI-First Engineer 的第 4 周讲授。
- Claude Code 是 Anthropic 的智能体编程工具，两门课程都基于它。
- Skill 打包了 Claude 在需要时可以加载的指令（The AI-First Engineer 第 3 周）。
